# victorable-shuorenhua（说人话）

> 业务与职场文案去 AI 味改写 Skill。专克伪导师鸡汤、生造隐喻、二元假对比与大词包装；只降调、不加戏。

## 背景

许多经过“二次润色”的文本虽然避开了“赋能、闭环”等老套大词，却落入了新型 AI 陷阱：从“咨询八股”跳进“营销号网文腔”——把“交换机”改成“人肉中转站”、把“杂事多”写成“被杂事生吞”。这种词看似接地气，实则极不自然、充满刻意感。

本 Skill 强调**事实白描**与**日常人话**：说同事之间平时真正会说的大白话，不造词、不升华、不加戏。

## 精简标志性改动对比（Before vs After）

每个案例只保留最具代表性的 1-2 处标志性改动，展示从“AI 假深沉”到“真实大白话”的核心差异：

### 案例 1：定性与结论（拒绝“生造对仗”与“刻意二元对比”）
* ❌ **AI 原版**：
  > “文涛不是‘不够努力’，而是被制度性摩擦力消耗了太多注意力。”
* ⚠️ **机械换皮**（依然假大空）：
  > “业务战功很硬，但你的精力正在被全链路的杂事生吞。”
* ✅ **日常人话**（就事论事直接陈述）：
  > “预售跑出了成绩，但你平时大部分时间全被各部门的零碎杂事占满了。”

---

### 案例 2：角色比喻（拒绝“生造机械隐喻”与“伪口语名词”）
* ❌ **AI 原版**：
  > “你目前的状态像是一台满负荷运转的交换机。”
* ⚠️ **机械换皮**（刻意生造，依旧不自然）：
  > “成了上下游的人肉中转站 / 人肉路由器。”
* ✅ **日常人话**（还原真实动作与工作状态）：
  > “谁找你都得转一道，成天在帮人传话对进度。”

---

### 案例 3：流程卡点（拒绝“书生气对策”，换成一线真实抓手）
* ❌ **AI 原版**：
  > “OA 等待直接咬掉发货窗口……建议与领导助理约定每周固定审批窗口，重大节点提前 3 天预约。”
* ✅ **日常人话**：
  > “OA 卡在领导那影响发货时间。紧急单子提交后直接发微信报备或当面找领导签批，并在 OA 顶部写明延误后果。”

---

### 案例 4：文末收尾（拒绝“假导师掏心窝”与“自我感动升华”）
* ❌ **AI 原版**：
  > “最后想说一点不那么‘报表’的话……你得到的是重新掌控时间的松弛感 —— 以及一个真正属于策略层的下一个 Q。”
* ✅ **日常人话**：
  > “把这些杂事理顺分流，后续才能把时间留给重点项目。”（删掉所有自设身份的煽情独白）

## 避坑与替换词表（规避用词 vs 真实人话）

| 场景 | 规避用词（AI 惊悚/造词） | 机械换皮（依然不自然） | 推荐用词（日常人话） |
| --- | --- | --- | --- |
| **沟通角色** | 满负荷的交换机 | 人肉中转站、人工路由器 | **谁找你都得转一道、成天帮人传话** |
| **精力占用** | 被杂事生吞 / 绞杀 / 血洗 | 注意力被蚕食 | **时间被杂事占满、天天在应付琐事** |
| **多线作战** | 在四个完全不同的战场奔跑 | 多线交织的战局 | **同时盯几个产品线 / 项目** |
| **流程阻滞** | 制度性摩擦力、结构性摩擦 | 机制性梗阻 | **流程卡顿、权责不清** |
| **人员协作** | 高频协作者拓扑 | 协作网核心节点 | **经常找你的几个同事 / 接口人** |
| **遗留问题** | 历史遗留责任真空 | 资产悬空断层 | **前任走后没结清的账 / 糊涂账** |
| **文档协同** | 资产与样品的唯一台账 | 唯一真实数据源（SSOT） | **一张共享在线表（谁要谁查）** |
| **假导师套话** | “想说一句实话……”、“不那么报表的话” | “平心而论”、“掏心窝子讲” | **直接删除，直接说事** |
| **虚假精确** | 预计回收 15%–20% 的时间 | 效率提升 30% | **每天能腾出约 2 小时** |
| **虚浮口号** | 找回松弛感、属于你的下一个 Q | 重塑职场掌控力 | **把手腾出来做重点项目** |

## 安装与使用

支持 Agent Skills 规范的工具（Claude Code / Codex / Cursor / OpenCode 等）：

```bash
npx skills add https://github.com/victorpaulee/victorable-shuorenhua
```

或手动克隆到 skills 目录：

```bash
git clone https://github.com/victorpaulee/victorable-shuorenhua ~/.claude/skills/victorable-shuorenhua
```

Codex 中运行：

```bash
codex exec -C . "读取 ./SKILL.md，按其中规则改写以下文本：[粘贴文本]"
```

   专注中文场景的高口碑改写规范。本项目借鉴了其“保事实、定责任人、只降调不加强”的原则，特别是在中文职场沟通中去除翻译腔与包装语的实战准则。
